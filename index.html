🚀 Quick Reference Cheat Sheet

Essential C++ syntax & concepts at your fingertips

📚 Basic Syntax

🔥 Program Structure:

#include <iostream>
#include <string>
using namespace std;
int main() {
    // Your code here
    return 0;
}

🔥 Variable Declarations:

int age = 25;              // Integer
double price = 19.99;      // Decimal number
char grade = 'A';          // Single character
string name = "John";      // String of characters
bool isTrue = true;        // Boolean (true/false)

🔥 Input/Output:

cout << "Hello World!";    // Output
cin >> variable;           // Input (stops at whitespace)
getline(cin, stringVar);   // Input entire line

🔄 Control Structures

🔥 IF-ELSE:

if (condition) {
    // code
} else if (condition2) {
    // code
} else {
    // code
}

🔥 LOOPS:

// For loop
for (int i = 0; i < 10; i++) {
    // code
}
// While loop
while (condition) {
    // code
}
// Do-while loop
do {
    // code
} while (condition);

🎯 Functions

🔥 Function Syntax:

returnType functionName(parameters) {
    // code
    return value;  // if not void
}
// Examples:
int add(int a, int b) {
    return a + b;
}
void printMessage() {
    cout << "Hello!";
}

📊 Arrays

🔥 Array Basics:

int arr[5];                    // Declaration
int arr[5] = {1, 2, 3, 4, 5}; // Initialization
int arr[] = {1, 2, 3};        // Size inferred
// Accessing elements
arr[0] = 10;   // First element
arr[4] = 50;   // Last element (for size 5)

🔗 Pointers

🔥 Pointer Basics:

int x = 10;
int* ptr = &x;     // ptr holds address of x
cout << *ptr;      // Dereference: get value at address
*ptr = 20;         // Change value through pointer

🚨 Common Mistakes

  • ❌ Using = instead of == in conditions
  • ❌ Array bounds violations (accessing arr[size])
  • ❌ Forgetting to initialize variables
  • ❌ Memory leaks (new without delete)
  • ❌ Missing base case in recursion
  • ❌ Integer division when expecting decimal
